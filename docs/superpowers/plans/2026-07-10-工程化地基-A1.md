# 工程化地基（A1·止血兜底）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 ashare-llm-analyst 达到"能 clone、能装依赖跑起来、入口能跑、配置有单一锚点、源码进 git 可回滚"的工程化基线，零业务逻辑改动。

**Architecture:** 五个任务串行——①建 `.gitignore` 安全网 → ②从 conda 环境导出 `environment.yml` + 重生 `requirement.txt` → ③修 `run_pipeline.sh` 入口 import → ④建根 `.env` + 调 `config.py` → ⑤一次性基线 commit。任务 1-4 改动停留工作区，任务 5 统一提交（主理人已确认"一次性基线 commit"）。

**Tech Stack:** conda（environment.yml）、pip（requirement.txt）、bash、git。

**Spec:** `docs/superpowers/specs/2026-07-10-工程化地基-A1-design.md`

**提交策略说明:** 任务 1-4 不单独提交；所有改动在任务 5 做一次性基线 commit。提交前需人工确认环境名、密钥未泄露。
